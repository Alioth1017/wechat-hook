

# wechat-hook

Un programa de hook para WeChat PC

# Preparación para el desarrollo

Wechat@2.8.0.112

[Microsoft Visual Studio 2019](https://visualstudio.microsoft.com/zh-hans/vs/whatsnew/)

[Boost 17.2.0](https://www.boost.org/)

## Consejos para la compilación

Para evitar errores de compilación, establezca la plataforma de solución activa en x86.
